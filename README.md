# 🫧🩵涼音◦°suzuneの歌える曲リスト

## ファイル
- `index.html`：ページ本体
- `style.css`：水色系・レスポンシブデザイン
- `app.js`：検索、タブ、折りたたみ、ダーク/ライト切替
- `songs.js`：曲データ本体（ここだけ編集すれば曲を追加・削除できます）

## スマホで使う
4ファイルを同じフォルダに置き、`index.html`をブラウザで開くだけです。

## 曲を追加する
`songs.js` の該当する `songs:[ ... ]` の末尾に、カンマ区切りで追加します。

例：
```js
songs:["既存曲","新しく追加した曲"]
```

曲名に `-another story-`、`−3`、`(1番まで)`、`+5オク下？` などがある場合も、文字列をそのまま追加してください。

## 分類を追加する
ボカロPなら、ボカロ欄の `categories` に同じ形式の分類を追加できます。
追加したボカロPは表示時に五十音順へ自動整列します。

## 将来の拡張
曲は内部的に `{ title, status, genre, season, work }` 形式へ拡張できる設計です。
現在は全曲を `status:"歌える"` として初期化しています。今後「覚え中」「練習中」「保留」などへ変更し、条件検索を追加できます。

※元データに 〖...〗 が付いている分類は `categories`、【...】 が付いている分類は `items` として保持しています。


### 表記について
元データの 〖...〗 と 【...】 の階層を表示側で区別しています。ボカロは 〖ボカロP名〗 の直下に曲を表示し、HoneyWorks のように大分類直下が 【...】 のものもそのまま表示します。デレマスの 【複数人曲】 内の 〖夏曲〗・〖その他〗 も保持しています。
